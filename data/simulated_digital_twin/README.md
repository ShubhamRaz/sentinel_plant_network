# Simulated digital-twin data

Files generated by \`src/run_experiments.py\` are synthetic simulations using declared mathematical assumptions, seeded stochastic processes and the Protocol v2.0 controller. They are not downloaded public observations and are not field-trial measurements.

The legacy CSV files at the parent \`data/\` level are retained for traceability with the initial manuscript. New executions write fresh simulation data into this directory (or the \`data/simulated_digital_twin/\` folder beneath the selected output root). Preserve the generation seed, config file and source commit with every analysis.
